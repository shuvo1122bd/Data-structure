Theoretical Questions Explanation :
Question Analysis :
আমাকে একটি doubly linked list দিবে যেটার ভ্যালু হিসেবে থাকবে string. তারপর Q সমান query দিবে। সেই query অনুযায়ী অপারেশন চালাতে হবে।
যেমন ;
visit address -> এটা দেয়া থাকলে আমাকে linked list এর মধ্যে থাকা সেই  address কে খুজে বের করতে হবে এবং সেটাকে প্রিন্ট করতে হবে। যেমন ঃ visit phitron দেয়া থাকলে
phitron সেই linked list এ আছে কি না বের করতে হবে। যদি থাকে তাহলে সেটাকে প্রিন্ট করে হবে, না থাকলে "Not Available" প্রিন্ট করতে হবে।

prev -> এই query দেয়া থাকলে আমাকে বর্তমান address থেকে তার previous এ থাকা linked list এর ভ্যালু প্রিন্ট করতে হবে। যদি না থাকে তাহলে "Not Available" প্রিন্ট করতে হবে।
next -> এই query দেয়া থাকলে আমাকে বর্তমান address থেকে তার next এ থাকা linked list এর ভ্যালু প্রিন্ট করতে হবে। যদি না থাকে তাহলে "Not Available" প্রিন্ট করতে হবে।

Observation :
এখানে আমি singly/double বা STL list যা ইচ্ছা ব্যবহার করতে পারব।
