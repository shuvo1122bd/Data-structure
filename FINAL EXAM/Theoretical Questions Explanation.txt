Theoretical Questions Explanation :
Question Analysis :
এই প্রব্লেম এ আমাকে একটি Binary tree দেয়া হবে। আমাকে এই ট্রি এর outer side এর node প্রিন্ট করতে হবে। outer node
হলো যেই নোড শুধুমাত্র বাম সাইডে আছে এবং যেই নোড ডান সাইডে আছে। এককথায় tree এর বাম এবং ডান সাইডের সব বাহিরের নোড গুলার
ভ্যালু প্রিন্ট করতে হবে।

Observation :
Recursion এর মাধ্যমে এই প্রব্লেমটা সল্ভ করা যায়। আমি এখানে দুইটা ফাংশন বানাব। একটা বাম সাইডের outer node এর জন্য, আরেকটা ডান সাইডের outer node
এর জন্য। প্রথম ফাংশনকে কল করলে সব বাম সাইডের outer node প্রিন্ট করবে। দ্বিতীয় ফাংশনকে কল করলে সব ডান সাইডের outer node প্রিন্ট করবে।
এখানে কয়েকটা corner case রয়েছে যা আমি condition(if-else)এর মাধ্যমে কন্ট্রোল করতে পারব।
