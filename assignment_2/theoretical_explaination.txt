Theoretical Questions Explanation :
Question Analysis :
 আমাকে একটা single linked list দেয়া থাকবে। আমাকে চেক করতে হবে এখানে কোনো 
duplicate value আছে কি না এবং সেটাকে রিমুভ করতে হবে। এমন ভাবে প্রিন্ট করতে হবে
যাতে সেখানে কোনো duplicate value না থাকে।

Observation :
এখানে আমি কয়েক ভাবে সল্ভ করতে পারি। কিন্তু frequency array এর মাধ্যমে এটা খুব সহজে সল্ভ করা যাবে।
যেমন, ইনপুট নেয়ার সময় যদি আমি freq array ব্যবহার করে ওই value গুলা ইনপুট নেই যেটার count অ্যারেতে
0, মানে এর আগে সেই value ইনপুট নেয়া হয়নি, তাহলেই linked list এ আমার ওই value ইনপুট হবে যেটা আগে হয়নি।

Testcase Analysis :
 //ইনপুট
1 2 4 2 3 5 1 4 5 2 6 1 -1
এই অ্যারে এর মধ্যে duplicate value ইনপুট না নিলে আমার আউটপুট হবে -> 
1 2 4 3 5 6 

এখানে, 
1  = আছে ৩ বার।
2 = ৩ বার
4 = ২ বার
3 = ১ বার
5 = ২ বার
6 = ১ বার

আমাকে প্রতিটি value একবার করে প্রিন্ট করতে হবে।
